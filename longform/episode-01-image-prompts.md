# Episode 1 — Image Prompts (30 shots @ 10s + thumbnail)

Style matched to the channel's Shorts (verified against Part 8, Musharaka): flat 2D vector,
recurring cast, gold/blue disc motif, red = debt.

## How to use

Every final prompt = **STYLE ANCHOR + ", " + CHARACTER TOKEN(s) (when named) + ", " + shot prompt**.

**STYLE ANCHOR (prepend to all):**
> Flat 2D vector illustration with clean bold outlines, simple friendly facial features, minimal shading with subtle gradients, muted palette of navy blue, slate grey, khaki and soft brown, vibrant gold used only for money and wealth, red used only for debt, uncluttered stylized background, soft atmospheric lighting, 16:9 widescreen, no text

**CHARACTER TOKENS (substitute wherever a name appears):**
- **NARRATOR** = "young adult man with light skin and short neat brown hair, wearing a plain blue t-shirt and khaki pants"
- **BANKER** = "young adult man with light skin and short black hair, wearing a grey long-sleeved shirt and black pants"
- **STRANGER** = "young woman with light brown skin and dark hair tied back, wearing an olive-green sweater"

Consistency tips: generate all 30 in one session/seed family if your tool supports it; keep the
character token text identical in every prompt — never paraphrase it.
