Authorize a YouTube channel

Mints the refresh token that lets this repo's automation edit one channel. Everything happens in this browser — nothing is uploaded, logged, or sent anywhere except Google.

1 Your OAuth client

Google Cloud Console → APIs & Services → Credentials → your OAuth client. These identify the app, not a channel — they are the same values already stored as repository secrets.

Sign in with the account that owns the channel you want, and if Google shows a channel chooser, pick that channel. The token is bound to that choice and cannot be repointed afterwards.

2 Paste the address you land on

After you approve, the browser lands on a localhost page that fails to load. That is expected — the one-time code is in the address bar. Copy the whole address and paste it here.
