HOW TO USE THIS FILE
- Every VIDEO PROMPT is complete and self-contained. Copy one, paste into
  Seedance, set 9:16 / 5s / 1080p, generate. Character, wardrobe, lighting,
  camera move and style are already baked into each prompt.
- The NEGATIVE PROMPT is identical for all 11 clips. Paste once, leave it.
- Do NOT ask Seedance for on-screen numbers. Every price, fee and percentage
  is burned in during the edit. Prompts request blank/blurred screens for
  exactly this reason — generated text garbles and dates the frame.
- VO lines carry ElevenLabs v3 tags. Paste exactly as written, brackets included.
- CAPTION lines are what you burn on top.

CONSISTENCY WORKFLOW (do this before generating clip 2)
1. Generate CLIP 03 first — cleanest full-body view of AMIR.
2. Regenerate until the head is fully blank. Then save that frame.
3. Feed that frame back as the reference image on every clip containing AMIR
   (03, 05, 06, 11). Character drift is the #1 failure mode of this format.
4. On the free trial, generate in this order: 01 (the hook decides the video),
   then 03, then the rest. If the trial runs out, 01-07 alone is a video.
